# Netflix Movie Recommendation System

A content-based movie recommendation system that suggests similar movies based on the user's selected title using machine learning and NLP techniques.

## Overview
This project analyzes movie metadata and recommends movies with similar content. It uses text-based feature extraction and similarity calculations to identify movies related to the selected title.

## Technologies Used
- Python
- Pandas, NumPy
- Scikit-learn
- NLP
- CountVectorizer
- Cosine Similarity
- Streamlit
- Pickle

## Methodology
- Movie metadata preprocessing
- Feature combination and text processing
- Text vectorization using Bag of Words
- Similarity calculation using Cosine Similarity
- Recommendation of the top 5 similar movies

## Application
The project includes a Streamlit web application where users can select a movie and receive recommendations.
